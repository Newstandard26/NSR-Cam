# NSR Elite — Snapshot brand assets

Drop the official files here (exact names) and they'll be wired into the app:

- `logo-elite.png`     — the "NSR ★ ELITE" wordmark (white on transparent)
- `logo-nsr.png`       — the NSR house logo (black + blue, transparent bg)
- `logo-nsr-white.png` — white version of the house logo (for dark backgrounds)
- `favicon.ico`        — 32x32 (or `icon.png` 512x512 in /src/app for Next metadata)

Until the raster files are added, the app renders an inline SVG recreation of the
NSR ★ ELITE wordmark (src/components/brand.tsx). Brand blue ≈ #4DB8E8.
